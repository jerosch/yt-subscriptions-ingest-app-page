# yt-ingest-site

Static pages for a personal YouTube subscription archive tool, hosted via
GitHub Pages on a custom domain.

These pages exist to satisfy the branding requirements of the Google OAuth
consent screen (application home page, privacy policy, terms of service).

The tool itself is a private project and is not hosted here. No personal
data is published on these pages.

## Pages

- `index.html` — application home page
- `privacy.html` — privacy policy
- `terms.html` — terms of service
